# Credit Card Fraud Detection

This project is strictly for personal education and practice and makes no claim to practical or production utility.

## Project Progress & Notebooks

### 1. `credit_card_fraud.ipynb` (Initial Attempt — Synthetic Data)
In this notebook, I explored a credit card fraud dataset using exploratory data analysis (EDA), performed data preprocessing, trained an **XGBoost** model, and evaluated it with performance metrics. 

However, the dataset turned out to be synthetic and contains no meaningful signal, making the resulting XGBoost model inaccurate.

### 2. `credit_card_fraud_new_data.ipynb` (Current Work — New Dataset)
I am now building a new model in `credit_card_fraud_new_data.ipynb`. Currently, I am in the data analysis phase, and early inspection already shows that this dataset is much more promising for training a useful model.\
Link to the data: https://www.kaggle.com/datasets/neharoychoudhury/credit-card-fraud-data
